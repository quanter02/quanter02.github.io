# quanter02.github.io

공공통계로 만든 계산기와 데이터 분석 프로젝트를 모아 두는 사이트입니다.

- **아이·맞벌이 자산 계산기** (`/`): 나이, 소득, 결혼 나이, 자녀 계획, 맞벌이, 아파트 월세·전세·매매 조건으로
  65세까지 가구 순자산과 결과를 가장 크게 바꾸는 선택을 계산합니다. 모든 계산은 브라우저 안에서만 이루어집니다.
- **오락가락** (`/chord/`, AI 악기 독학 코칭): 카메라 화면에 지판 가이드를 맞추면 MediaPipe로 손가락 끝이 몇 번줄·몇 번 프렛에 있는지
  판정하고, 코드 수업과 곡 코드 진행 연습을 합니다. 영상과 기록은 브라우저 밖으로 보내지 않습니다.
- **조교 반복 업무 도우미 체험판** (`/tutor/`): 학원 원장님·강사님용. 예시 학생 3명의 약점 분석, 맞춤 학습지·정답지 인쇄, 학부모 리포트,
  줄어든 조교 시간 계산을 체험합니다. 검색 노출은 막아 두었고(noindex), 기록은 브라우저에만 저장합니다.
- **강의 조교 도우미 대학 체험판** (`/prof/`): 대학 교수님·대학원 조교용. 자료구조(Python) 퀴즈 예시로 반 전체 공통 오개념, 학생별 약점 분석,
  맞춤 연습문제·정답 인쇄, 학생 피드백, 줄어든 조교 시간 계산을 체험합니다. noindex, 기록은 브라우저에만 저장합니다.
- **무료 오답 분석기** (`/analyze/`): 엑셀 성적표를 붙여 넣으면 문항별 정답률·많이 고른 오답·변별도, 반 전체 약점 유형,
  학생별 약점과 피드백 초안을 보여 줍니다. 계산은 브라우저 안에서만 하고 성적표는 저장·전송하지 않습니다.
