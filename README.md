# quanter02.github.io

공공통계로 만든 계산기와 데이터 분석 프로젝트를 모아 두는 사이트입니다.

- **아이·맞벌이 자산 계산기** (`/`): 나이, 소득, 결혼 나이, 자녀 계획, 맞벌이, 아파트 월세·전세·매매 조건으로
  65세까지 가구 순자산과 결과를 가장 크게 바꾸는 선택을 계산합니다. 모든 계산은 브라우저 안에서만 이루어집니다.
- **기타 코드 손 모양 판정** (`/chord/`): 코드 사진을 올리면 MediaPipe로 손 관절을 찾아 학습하고,
  웹캠으로 지금 잡은 손이 그 코드인지 판정합니다. 사진은 서버로 보내지 않습니다.

데이터 출처: KOSIS 국가통계포털(고용노동부 고용형태별근로실태조사, 통계청 인구총조사·인구동향·소비자물가),
한국보건사회연구원 2021 가족과 출산조사, 한국부동산원 아파트 실거래가격·전월세전환율.
